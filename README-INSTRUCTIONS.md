# FerMorell GitHub Profile

1. Create a GitHub repository named exactly `FerMorell`.
2. Put `README.md` in the repository root.
3. Put the whole `assets/` folder beside it.
4. Commit and push.

The README references the SVG files with relative paths, so the assets must stay inside `assets/`.

The radar graphics are intentionally presented as "focus" maps, not numerical skill ratings.
